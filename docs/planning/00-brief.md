## 0. 이번 리디자인 제안 — `MARKET TAPE`

현재 구현은 기능과 상태 계약은 갖추었지만, 옅은 배경·동일한 카드·넓은 여백이 반복되어 일반 SaaS 대시보드처럼 보이고 주식 시장을 읽는 순간성이 약하다. 이번 작업은 기능을 늘리는 것이 아니라 **장중 시장판을 읽고 → 종목을 좁히고 → 근거를 검증하는 흐름**을 시각적으로 재편한다.

- 데스크톱은 긴 사이드바 대신 압축된 상단 명령 바와 시장 테이프를 사용한다.
- 캔버스는 잉크 네이비와 따뜻한 리서치 페이퍼를 조합하고, 상승/하락은 한국 시장 관습인 빨강/파랑을 텍스트·기호와 함께 사용한다.
- 시장 화면은 KOSPI/KOSDAQ, 거래대금, 급등·급락, 신호 레이더를 첫 화면의 주인공으로 만든다.
- 종목 상세는 가격 흐름, 수급, 뉴스, 재무, 신호 근거를 하나의 리서치 도시에처럼 연결한다.
- API·권한·데이터 freshness 계약은 유지하고, 표현 계층·레이아웃·컴포넌트 상태를 재설계한다.

이 방향은 제안이며 사용자 승인 전 구현 기준이 아니다.

## 1. 문제

국내 개별주식 투자자는 시세·수급·뉴스·재무·알고리즘 신호를 여러 서비스에서 따로 확인해야 한다. 신호가 언제 발생했는지, 어떤 근거와 알고리즘 버전으로 산출됐는지, 현재 데이터가 실시간인지 지연인지도 한 화면에서 신뢰하기 어렵다.

## 2. 제품 정의

실시간 국내 개별주식 데이터와 근거가 설명된 매수·매도 알고리즘 신호를 제공하는 구독형 리서치 웹 서비스다. 주문·계좌·자산관리 기능은 제공하지 않으며, 사용자가 판단할 수 있도록 데이터 상태와 위험 고지를 우선한다.

## 3. 대상 사용자

- 국내 개별주식을 직접 분석하는 개인 투자자
- 여러 데이터 소스를 하나의 화면에서 확인하려는 사용자
- 알고리즘 신호를 참고하되 근거와 신선도를 검증하려는 사용자
- 관심종목을 추적하고 시장 흐름을 빠르게 파악하려는 사용자

## 4. 목표

1. 시장 전체에서 관심 종목과 이상 움직임을 빠르게 발견한다.
2. 종목 상세에서 가격·수급·뉴스·재무·신호 근거를 한 흐름으로 확인한다.
3. 무료 사용자와 구독 사용자의 권한 차이를 명확하고 정직하게 보여준다.
4. 모든 실시간 정보에 기준 시각, 지연 여부, 데이터 상태를 표시한다.
5. 신호를 투자 권유가 아닌 참고용 분석 결과로 이해하도록 위험을 고지한다.

## 5. 비목표

- 주문 실행, 계좌 연결, 잔고·포트폴리오 관리
- 모바일 네이티브 앱
- ETF·ETN·펀드 제공
- 종목 간 비교 기능
- 웹 푸시·문자·이메일 알림
- 투자일임, 자동매매, 수익 보장

## 6. MVP 범위

- 회원가입 및 간편로그인
- 시장 개요와 국내 개별주식 검색
- 실시간 또는 공급자 기준의 최신 시세 표시
- 실시간 알고리즘 매수·매도 신호 표시(월 구독자 전용)
- 종목 상세: 차트, 수급, 뉴스, 재무, 신호 이력
- 사전 승인된 구조화 조건 스크리너
- 관심종목 추가·목록·재방문·삭제
- 월 구독 sandbox/승인된 결제 흐름, 권한·만료·결제 실패·취소 상태 안내
- 로딩·빈 상태·오류·지연·실시간 장애 상태

### MVP 후속 또는 별도 승인

인사이트 콘텐츠 범위, 성과 대시보드, AI 점수, 자연어 스크리너, 저장 필터, 외부 알림은 별도 PRD·권한·데이터·법무 승인이 없으면 MVP 화면과 티켓에 포함하지 않는다.

## 7. 핵심 원칙

- 신호보다 근거와 데이터 상태를 먼저 보여준다.
- 무료/프리미엄 경계를 숨기지 않는다.
- 최신성은 숫자와 기준 시각으로 표현한다.
- 모든 주장에는 산정 기준과 제한사항을 붙인다.
- 사용자가 다음 행동을 이해할 수 있도록 화면 상태를 설계한다.

## 8. 성공 기준(제안)

- 신규 사용자가 60초 안에 시장에서 종목 상세까지 도달
- 종목 상세에서 시세 기준 시각과 데이터 상태를 90% 이상이 인지(사용성 테스트)
- 구독 사용자가 신호 근거·발생 시각·알고리즘 버전을 확인할 수 있음
- WebSocket/SSE 재연결 후 중복·역순 이벤트가 화면에 반영되지 않음
- 무료 사용자가 잠긴 신호의 이유와 구독 경로를 이해함

수치 목표와 측정 기간은 트래픽·공급자 SLA·법무 검토 후 확정한다.

## 9. 사실 / 가정 / 제안 / 미결정

### 사실·현재 합의

- 국내 개별주식만 제공
- 고객용 반응형 웹 우선
- 신호는 월 구독자에게만 제공
- 주문·계좌·모바일 앱·알림·비교 기능은 1차 제외
- 디자인 승인 후 구현

### 가정

- 통합된 기준 시각·근거·권한 표시가 신뢰와 구독 이해도를 높일 것이다.
- 대표 종목 수직 슬라이스가 공급자·이벤트·권한 리스크를 가장 빨리 드러낼 것이다.

### 제안

- 시그널 제품명은 `실시간 시그널`로 통일
- 저장 상태와 화면 표시 상태를 구분해 신호 상태를 표현
- 기본 화면은 정보 밀도가 높은 금융 터미널 방향으로 설계

### 미결정

- 월 구독 가격, 자동갱신, 환불정책, 결제대행사
- 간편로그인 제공자
- 실시간 시세 공급자, 재배포 권한, SLA와 비용
- 알고리즘 재계산 기준, 신호 유효기간, 성과 산정 방식
- 우선주·스팩·리츠 포함 여부
- 매수·매도 표현과 금융 규제·고지 문구의 법무 승인
