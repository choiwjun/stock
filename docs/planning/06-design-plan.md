# 06. Design Plan

## 문서 상태

기존 `MARKET TAPE / 장중 리서치 데스크`와 `EVIDENCE TAPE / 근거 우선 리서치 데스크` 구현을 baseline으로 기록한다. 사용자 피드백을 반영해 `Chainx-inspired EVIDENCE DESK / 다크 투자 리서치 커맨드센터`로 시각 방향을 전환한 승인안을 담는다. 새 방향은 `06-design-spec.md`와 티켓의 구현 기준으로 승격하며, 실제 상용 출시는 별도 공급자·법무·운영 승인을 필요로 한다.

## 1. 방향 — `Chainx-inspired EVIDENCE DESK / 다크 투자 리서치 커맨드센터` (사용자 승인)

**Chainx – Stock Investment의 대시보드 밀도·위젯 구조·시각적 완성도를 참고한 다크 금융 리서치 터미널**을 지향한다. Chainx의 화면을 복제하지 않고, 상단 마켓 티커·데스크톱 사이드바·KPI 위젯·차트 컨트롤·어두운 레이어·보라색 인터랙션 액센트를 시그널랩의 국내 개별주 리서치 문맥으로 재해석한다.

핵심 인상은 `시장 상태 스캔 → 움직이는 종목 발견 → 현재가·가격 흐름 → 수급·뉴스·재무·근거 확인`이다. 다크 캔버스와 카드형 위젯은 채택하되, 금융 상태는 색상만으로 표현하지 않는다. 한국 시장의 상승 레드·하락 블루, 기준 시각·출처·신선도·권한 상태, 차트의 동등한 데이터 표는 유지한다. 프리미엄은 네온 장식이 아니라 더 깊은 근거·신선도·이력 접근으로 인식되게 한다.

### Chainx에서 배우되 복제하지 않는 것

- 채택: 상단 시장 ticker, 좌측 데스크톱 navigation, 강한 KPI 숫자, 위젯 그리드, chart toolbar, compact action cluster, 명확한 active state
- 재해석: Chainx의 포트폴리오·잔고·매수 CTA를 시장 폭·종목 탐색·근거 패널로 교체
- 보존: 국내 개별주 범위, API·권한·freshness·신호 공개 정책, WCAG 2.2 AA, 모바일 하단 탭
- 금지: 원본 로고·카피·화면을 복사하거나, 비구독자에게 실제 프리미엄 신호를 추론할 수 있는 시각 정보를 노출

## 2. 설계 원칙

1. 데이터 상태를 숫자와 라벨로 표시한다.
2. 신호 방향보다 발생 시각·유효기간·근거를 함께 설명한다.
3. 무료/프리미엄 경계를 숨기지 않는다.
4. 색상·아이콘·위치만으로 의미를 전달하지 않는다.
5. 사용자가 다음 행동과 복구 방법을 알 수 있어야 한다.
6. 신호를 투자 권유·수익 보장으로 오해할 수 있는 장식을 피한다.

## 3. 토큰 기준

구체적인 기준값과 화면별 적용은 [`06-design-spec.md`](./06-design-spec.md)를 따른다. 구현 전 자동 대비 검사와 실제 화면 수동 검증을 수행한다.

### 리디자인 토큰 제안

| 토큰군 | 제안 | 사용 원칙 |
|---|---|---|
| 프레임 | `ink-950` 캔버스, `ink-900` chrome, `ink-800` panel, violet accent | Chainx-inspired 다크 레이어와 제품 chrome을 분리 |
| 상승 | `rise-700` 레드 + `↑`/`상승` | 한국 시장 관습, 색상 단독 사용 금지 |
| 하락 | `fall-700` 블루 + `↓`/`하락` | 한국 시장 관습, 색상 단독 사용 금지 |
| 실시간 | `live-500` 청록 | LIVE 상태와 연결 상태에만 사용 |
| 경고 | `amber-500` 앰버 | stale·지연·확인 필요 상태 |
| 인터랙션 | `violet-500` 퍼플 + 텍스트/포커스 | 선택·주요 CTA·차트 강조에 사용; 상승/신호 방향 의미로 사용 금지 |
| 수치 | `ui-monospace`/tabular figures | 가격·등락·거래량 정렬과 빠른 비교 |
| 표면 | 낮은 대비의 규칙선, 12~16px 반경, 제한된 shadow | 반복 카드 soup와 과도한 네온 효과 방지 |

색상 대비는 WCAG 2.2 AA 이상을 통과해야 하며 rise/fall/live/stale는 텍스트·아이콘·상태 라벨을 함께 제공한다.

### 기존 공통 토큰 계약

| 토큰군 | 기준 규칙 | 적용 기준 |
|---|---|---|
| 색상 | surface/text/border/status/interactive 역할 토큰 | 모든 조합 WCAG AA 대비 |
| 상태색 | 상승/하락/중립/경고/오류를 텍스트·기호와 병기 | 색맹·흑백에서도 판별 |
| 간격 | 4/8 기반, 데이터 셀과 설명 영역의 밀도 분리 | 320px·확대 환경에서 잘림 없음 |
| 타입 | 제목/본문/라벨/수치/표 숫자 역할 분리, tabular figures | 숫자 비교·한글 가독성 |
| 그리드 | 데스크톱 다중 열, 모바일 1열/우선 열 | 주요 흐름 CLS와 가림 없음 |
| 모션 | 연결·업데이트·상태 전환 최소 모션 | reduced motion·깜박임 제한 |

## 4. 컴포넌트 계약

모든 핵심 컴포넌트는 `default`, `loading`, `empty`, `error`, `stale`, `permission-locked`, `degraded`, `selected`, `keyboard-focus`를 정의한다.

- `DataFreshnessBadge`: `asOf`, `receivedAt`, `dataStatus`, `staleAfter`
- `SignalCard/Table`: 권한별 필드, 상태, 방향, 발생/발행 시각, 유효기간
- `SubscriptionGate`: `AUTH_REQUIRED`, `ENTITLEMENT_REQUIRED`, `REVOKED`, CTA
- `EntitlementStatus`: active/pending/cancellation-scheduled/refund-pending/payment-failed/expired
- `ReconnectBanner`: 연결 상태, 마지막 정상 시각, replay/resync 결과, 재시도
- `RiskDisclosure`: 고지 ID·버전·표시 위치·동의 필요 여부
- `StockSearch`: query, loading, empty, validation, 결과 권한

## 5. 상태와 콘텐츠

신호 방향·신호 상태·데이터 신선도·연결 상태·권한 상태를 색상 하나로 합치지 않는다. 엔진 heartbeat가 오래되면 UI는 저장된 과거 신호를 최신 신호처럼 강조하지 않고 `SUSPENDED` 또는 `STALE`의 원인을 설명한다.

## 6. 접근성 수용 기준

- 모든 조작 요소 키보드 접근·visible focus
- 차트는 텍스트 요약과 탐색 가능한 데이터 표를 함께 제공
- 상승/하락은 텍스트·기호와 함께 표현
- 실시간 업데이트는 필요한 상태만 `aria-live="polite"`로 알림
- 모달/바텀시트 포커스 이동·복귀 보장
- 오류 메시지와 입력을 연결하고 해결 행동 제공
- reduced motion 지원, 깜박임 제한
- 확대/리플로, 320px, 터치 타깃, 포커스 가림을 테스트

## 7. 필수 상태 프로토타입

시장, 종목 상세, 잠금 신호, 활성 신호, 구독 처리중, 결제 실패, 해지 예정, 환불 처리중, 스트림 stale, replay 성공/실패, 로그인 만료, 관심목록 empty/saved/delete를 실제 화면으로 만든다.

## 8. 검증 계획

### 사용성 과제

- 기준 시각과 stale 여부 찾기
- 무료 사용자에게 잠금 신호의 의미 설명
- 종목 추가 후 재방문·삭제
- 구독 처리중과 활성 상태 구분
- 신호 방향·근거·위험 고지의 관계 설명
- 연결 장애 후 복구

### 통과 조건

과제별 성공률·오해 유형·도움 요청·완료 시간·중대한 금융 오해를 기록한다. 결과가 없는 상태에서 WCAG 또는 디자인 완성을 선언하지 않는다.

## 9. 잔여 제품·출시 결정

디자인 게이트에서 브랜드 폰트 폴백, Chainx-inspired 다크 기본값, 의미 색상, 상태 표현 원칙, 실데이터와 잠금 미리보기의 구분을 확정했다. 다음 항목은 디자인과 별도로 제품·기술·법무 승인이 필요하다.

- 구독 가격·자동갱신·환불·결제대행사
- 간편로그인 제공자와 동의 문구
- 시세 공급자·재배포권·SLA·비용
- 알고리즘 재계산 기준·신호 유효기간·성과 산정 방식
- 우선주·스팩·리츠 포함 여부
- 매수·매도 표현 및 금융 규제·고지 문구
- 개인정보 보존·삭제·백업 재적용 정책
- RPO/RTO, replay 보존기간, `staleAfter`, 권한 회수 최대 지연

이 항목이 승인되기 전에는 상용 결제와 실제 프리미엄 신호를 공개하지 않는다.
