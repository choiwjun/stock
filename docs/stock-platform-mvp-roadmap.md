# 주식 플랫폼 MVP 작업분해·로드맵 v0.1

> **정본 안내:** 이 문서는 초기 로드맵 참고자료다. 정본은 [`docs/planning/11-mvp-roadmap.md`](planning/11-mvp-roadmap.md)와 [`docs/planning/13-tickets.md`](planning/13-tickets.md)다. 계층별 완료가 아니라 대표 종목 수직 슬라이스·권한 회수·replay·결제 생명주기 기준을 사용한다.

## 1. MVP 목표

무료 실시간 국내 주식 정보와 월 구독 기반 실시간 매수·매도 알고리즘 신호를 하나의 고객용 웹 흐름으로 검증한다.

핵심 흐름:

```text
시장 확인
→ 종목 검색/스크리너
→ 종목 분석
→ 월 구독
→ 실시간 매수·매도 신호
→ 관심종목 저장
→ 성과 확인
```

## 2. 수직 슬라이스 우선

처음부터 모든 종목·모든 화면을 만드는 대신 다음 흐름을 대표 종목 1개로 먼저 완성한다.

```text
시세 공급자
→ 대표 종목 quote 수신
→ 알고리즘 신호 계산
→ 신호 API 저장
→ WebSocket 전달
→ 무료 사용자 잠금
→ 월 구독 결제
→ 프리미엄 사용자 신호 노출
```

이 수직 슬라이스가 통과한 뒤 종목 수, 랭킹, 스크리너, 뉴스·재무 범위를 확장한다.

## 4. 권장 작업 순서

### 단계 0 — 계약 동결

선행 작업:

- 무료/프리미엄 권한표
- API 계약
- 신호 상태 모델
- 데이터 공급자·결제대행사
- 투자정보 고지

완료 기준:

- 화면·API·알고리즘이 동일한 용어를 사용한다.
- `signalType`, `status`, `asOf`, `sequence` 의미가 확정된다.
- 미결정 항목마다 담당자와 결정 기한이 있다.

### 단계 1 — 기반·인증

포함 작업:

- 사용자·인증
- 종목 마스터
- 기본 API 셸
- 관계형 저장소
- 로그·추적 ID
- 기본 웹 셸

완료 기준:

- 회원가입과 간편로그인이 동작한다.
- 보호된 API가 사용자 권한을 확인한다.
- 종목코드로 종목 기본정보를 조회할 수 있다.

### 단계 2 — 실시간 수직 슬라이스

포함 작업:

- 대표 종목 quote 수신
- quote 저장·캐시
- 신호 엔진 연결
- signal 저장
- WebSocket 연결
- 종목 분석 화면 반영

완료 기준:

- 공급자 이벤트가 화면까지 전달된다.
- quote 시각과 signal 시각이 분리 표시된다.
- 연결 끊김 후 REST 스냅샷과 스트림 재연결이 동작한다.
- 중복·역순 이벤트가 화면을 오염시키지 않는다.

### 단계 3 — 무료/프리미엄 흐름

포함 작업:

- 신호 잠금
- 월 구독 상품
- 결제 승인 웹훅
- Entitlement 판정
- 결제 사용자 스트림 허용
- 만료·해지·실패 처리

완료 기준:

- 무료 사용자는 signal payload를 받을 수 없다.
- 승인된 구독자만 실시간 신호를 볼 수 있다.
- 결제 중복 웹훅이 중복 권한을 만들지 않는다.
- 만료 즉시 신호 조회와 스트림이 제한된다.

### 단계 4 — 탐색·리서치 확장

포함 작업:

- 시장 대시보드
- AI 랭킹
- 조건 스크리너
- 수급 탭
- 뉴스·공시
- 기본 재무
- 관심종목
- 성과 화면

완료 기준:

- 시장 → 시그널 → 종목 분석 흐름이 끊기지 않는다.
- 관심종목을 저장하고 실시간 상태를 볼 수 있다.
- 스크리너 결과에서 종목 분석으로 이동할 수 있다.
- 성과 산정 기준과 실제/백테스트 구분이 표시된다.

### 단계 5 — 베타·출시 준비

포함 작업:

- 대표 종목에서 전체 대상 종목으로 확장
- 데이터 공급자 장애 훈련
- 결제 실결제·환불 검증
- 접근성·반응형 검증
- 부하·연결 수 검증
- 운영 대시보드와 알람
- 법률·약관 최종 검토

## 5. 핵심 의존성

```text
종목 마스터
  ↓
시세 공급자·정규화
  ↓
신호 엔진 입력
  ↓
신호 저장·이벤트
  ↓
API·WebSocket
  ↓
웹 화면

인증
  ↓
결제
  ↓
웹훅 검증
  ↓
구독 권한
  ↓
프리미엄 신호
```

병렬 가능 작업:

- 와이어프레임·UI 디자인 ↔ 데이터 계약
- 인증 화면 ↔ 시세 수집기
- 뉴스·재무 수집 ↔ 결제 화면
- 접근성 기준 ↔ 컴포넌트 개발

## 6. 릴리즈 게이트

### Gate A — 계약 게이트

- API 계약과 도메인 용어집 승인
- 무료/프리미엄 기능표 승인
- 데이터 공급자 계약 확인

### Gate B — 데이터 게이트

- quote 신선도 목표 충족
- sequence·중복·재연결 테스트 통과
- 시세 장애 시 안전한 상태 표시

### Gate C — 수익화 게이트

- 결제 승인·실패·환불 테스트 통과
- 웹훅 idempotency 통과
- 권한 없는 사용자의 signal 접근 차단

### Gate D — 알고리즘 게이트

- 신호 상태 전이 검증
- 알고리즘 버전 기록
- 실제 신호와 백테스트 구분
- 신호 성과 산정 검증

### Gate E — 출시 게이트

- 접근성·반응형 검증
- 부하·장애 복구 검증
- 개인정보·약관·금융 고지 검토
- 운영 담당자에게 장애 대응 절차 전달

## 7. MVP Definition of Done

- 사용자가 회원가입 또는 간편로그인을 할 수 있다.
- 시장과 종목의 실시간 시세를 확인할 수 있다.
- 기본 차트와 수급을 볼 수 있다.
- AI 점수와 시그널 목록을 확인할 수 있다.
- 무료 사용자는 프리미엄 신호가 잠긴다.
- 월 구독 결제 후 서버 승인으로 권한이 활성화된다.
- 구독자는 실시간 매수·매도 신호를 확인할 수 있다.
- 신호 변경과 신호 이력을 확인할 수 있다.
- 관심종목을 저장하고 페이지 내 실시간 상태를 확인할 수 있다.
- 시세·알고리즘·결제 장애가 사용자에게 안전하게 표시된다.
- 핵심 흐름에 대한 자동·수동 테스트가 통과한다.
