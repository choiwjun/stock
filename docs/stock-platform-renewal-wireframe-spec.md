# 주식 플랫폼 리뉴얼 와이어프레임 명세 v0.1

> **정본 안내:** 이 문서는 초기 화면 참고자료다. 정본은 [`docs/planning/05-wireframe-spec.md`](planning/05-wireframe-spec.md), [`docs/planning/04-user-flow.md`](planning/04-user-flow.md), [`docs/planning/02-prd.md`](planning/02-prd.md)다. 자연어 스크리너·AI 점수·고도화 성과·저장 필터는 별도 승인 전 MVP 화면에 포함하지 않는다.

## 1. 범위

- 고객용 반응형 웹
- 국내 개별 주식 중심
- 실시간 시세 및 실시간 매수·매도 알고리즘 신호
- 월 구독 기반 프리미엄 신호
- 주문·계좌·ETF·ETN·펀드·웹 알림·종목 비교 제외

## 2. 공통 셸

```text
[Skip link]
[Logo] [시장] [실시간 시그널] [조건 스크리너] [종목 분석] [인사이트] [관심종목]
                         [검색] [구독] [로그인/프로필]
-----------------------------------------------------------------------
                         본문
-----------------------------------------------------------------------
[FAQ] [약관] [개인정보처리방침]
```

- 전역 검색은 종목명·종목코드·초성 검색을 지원한다.
- 현재가와 알고리즘 신호의 기준 시각을 분리해 표시한다.
- 로그인 전에도 공개 데이터는 탐색할 수 있고, 저장·프리미엄 신호에서 인증을 요청한다.

## 3. 시장 대시보드 `/market`

### 우선순위

1. 시장 상태와 실시간성
2. 오늘의 시장 요약
3. 실시간 시그널 진입
4. 수급·업종 흐름
5. 뉴스·공시

```text
H1 오늘의 시장                         [장중] [마지막 갱신 10:32:14]

[코스피] [코스닥] [나스닥] [S&P500] [원·달러]

┌─────────────────────────────┬─────────────────────────────┐
│ 오늘의 시장 브리핑            │ 주요 실시간 시그널             │
│ H2                           │ H2                          │
│ 3~5줄 요약                   │ 매수/매도 신호 종목 목록        │
│ [전체 인사이트 보기]          │ [전체 시그널 보기]             │
├─────────────────────────────┴─────────────────────────────┤
│ 업종·테마 흐름 / 외국인·기관·개인 수급                           │
├───────────────────────────────────────────────────────────────┤
│ 주요 뉴스·공시                                                     │
└───────────────────────────────────────────────────────────────┘
```

- 시장 지수 카드는 `장전·장중·장마감·휴장` 상태를 포함한다.
- 상승·하락은 색상과 텍스트를 함께 사용한다.
- 글로벌 지수와 환율은 국내 시장 판단을 위한 보조 지표로 표시한다.

## 4. 실시간 시그널 `/signals`

```text
H1 실시간 시그널                   [실시간 연결됨] [시그널 성과]

[전체] [매수] [매도] [신규 발생] [관심종목]
[시장 ▼] [업종 ▼] [AI 점수 ▼] [정렬 ▼]             [검색]

┌──────┬──────┬──────┬──────┬────────┬────────┬──────┐
│ 종목  │ 현재가 │ 등락률 │ 점수  │ 신호    │ 발생시각 │ 수급 │
├──────┼──────┼──────┼──────┼────────┼────────┼──────┤
│ ...  │ ...  │ ...  │ ...  │ 매수    │ 10:32  │ ...  │
└──────┴──────┴──────┴──────┴────────┴────────┴──────┘
```

### 무료 사용자

- 신호 결과 대신 프리미엄 잠금 상태를 표시한다.
- 종목 기본정보와 AI 점수는 정책 범위 안에서 제공한다.
- `[월 구독 시작하기]`로 이동한다.

### 구독 사용자

- 신호 변경을 실시간 반영한다.
- 행 선택 시 종목 분석으로 이동한다.
- 신호 근거, 알고리즘 버전, 기준 시각을 볼 수 있다.
- 동일 신호 유지 이벤트는 중복 노출하지 않는다.

## 5. 종목 분석 `/stocks/{code}`

```text
breadcrumb: 시장 > 실시간 시그널 > 종목 분석

H1 삼성전자     260,500원  +3.17%  [실시간]
[관심종목 등록] [신호 이력]

┌─────────────────────────────┬─────────────────────────────┐
│ AI 점수 82점                 │ 알고리즘 신호                  │
│ 점수 변화 +4                 │ 매수 신호                      │
│ 긍정 요인 3개 / 위험 요인 2개 │ 발생 10:32 / v2.4             │
└─────────────────────────────┴─────────────────────────────┘

[요약] [AI 분석] [차트] [수급] [재무정보] [뉴스·공시] [신호 이력]

현재 탭 콘텐츠
```

- 알고리즘 신호는 월 구독 권한을 서버에서 확인한다.
- 현재가 기준 시각과 신호 발생 시각을 별도로 표시한다.
- 기본 차트에는 거래량과 신호 발생 지점을 표시한다.
- 수급 탭은 외국인·기관·개인 순매수와 기간별 추이를 제공한다.
- 신호 이력에는 상태 변경만 기록한다.

## 6. 조건 스크리너 `/screener`

```text
H1 조건 스크리너

[문장으로 조건을 입력하세요                           ] [분석]
예: 외국인 수급이 좋아지고 영업이익이 증가하는 코스피 종목

생성된 조건
[코스피 ×] [외국인 순매수 증가 ×] [영업이익 성장 ×]

[조건 추가] [초기화]                              [결과 보기]

검색 결과 128개                         [정렬 ▼] [저장]
┌──────┬──────┬──────┬──────┬────────┬────────┐
│ 종목  │ 현재가 │ AI점수 │ 수급  │ 신호    │ 분석    │
└──────┴──────┴──────┴──────┴────────┴────────┘
```

- 자연어 입력 결과를 사용자가 확인·수정할 수 있어야 한다.
- 필터 해석 실패 시 임의로 실행하지 않고 수정 안내를 제공한다.
- 결과 없음, 데이터 지연, 조건 오류 상태를 구분한다.
- 종목 비교는 제공하지 않는다.

## 7. 월 구독 `/pricing`

```text
H1 실시간 알고리즘 신호 이용하기

┌────────────────────────────────────────┐
│ 월 구독                                 │
│ 매수·매도 알고리즘 신호                  │
│ ✓ 실시간 매수 신호                       │
│ ✓ 실시간 매도 신호                       │
│ ✓ 신호 근거·이력                         │
│ ✓ 전체 시그널 랭킹                       │
│                                          │
│ 월 ₩가격                                  │
│ [월 구독 시작하기]                        │
│ 자동 갱신·해지·환불 정책                  │
└────────────────────────────────────────┘

투자 위험 고지 및 알고리즘 한계
```

- 결제 전 자동 갱신 여부와 해지 정책을 명확히 표시한다.
- 결제 완료 화면만으로 권한을 활성화하지 않고 서버 승인 후 활성화한다.
- 결제 실패·만료·해지·환불 상태를 별도로 안내한다.

## 8. 공통 상태

| 상태 | 요구사항 |
|---|---|
| 로딩 | 콘텐츠 위치를 유지하는 스켈레톤 표시 |
| 실시간 연결 중 | 연결 상태와 마지막 정상 시각 표시 |
| 연결 끊김 | 재연결 중, 수동 재시도 제공 |
| 데이터 지연 | 지연 여부와 기준 시각 표시 |
| AI 처리 중 | 이전 결과와 처리 상태 구분 |
| 신호 없음 | 중립/없음과 데이터 기준일 표시 |
| 권한 없음 | 신호 결과를 노출하지 않고 구독 CTA 표시 |
| 결제 실패 | 원인, 재시도, 고객지원 경로 제공 |
| 결과 없음 | 원인과 다음 행동 안내 |

## 9. 반응형·접근성

- 데스크톱 기준으로 설계하되 768px 이하에서 카드·테이블을 재배치한다.
- 시그널 테이블은 모바일에서 종목 카드로 전환한다.
- 색상만으로 매수·매도를 구분하지 않는다.
- 차트에는 핵심 수치 요약 또는 데이터 테이블을 제공한다.
- 모든 탭·필터·검색·구독 CTA를 키보드로 이용할 수 있어야 한다.
- 실시간 변경은 보조기술에 과도한 반복 알림을 보내지 않는다.
- 페이지별 H1은 하나만 사용한다.

## 10. 착수 전 미결정

- 월 구독 가격과 결제대행사
- 간편로그인 제공자
- 무료 사용자에게 공개할 AI 점수 범위
- 실시간 알고리즘 신호의 재계산 임계값
- 우선주·스팩·리츠 포함 여부
- 시세 공급자의 실시간 사용권과 장애 SLA
- 투자정보 고지 및 성과 표시 문구
